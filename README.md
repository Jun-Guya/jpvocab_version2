# 일본어 단어장 (JLPT N1 · 41일차 · 4,045단어)

## 아이패드에 설치하기
1. 이 폴더의 파일 8개를 GitHub 저장소에 올립니다.
   - 이미 올려 둔 저장소가 있다면 **Add file → Upload files**로 같은 이름의 파일을 덮어쓰면 됩니다.
2. 저장소의 **Settings → Pages**에서 Branch를 `main`과 `/ (root)`로 고르고 **Save**를 누릅니다.
   - 이미 설정했다면 다시 할 필요 없습니다.
3. 1~2분 뒤 `https://내아이디.github.io/저장소이름/` 주소를 아이패드 **Safari**로 엽니다.
4. **공유 버튼(□↑) → 홈 화면에 추가**를 누르면 설치됩니다.

## 들어 있는 것
- 1~41일차 **4,045단어** 전체가 기본 내장되어 있습니다. 엑셀을 따로 불러오지 않아도 바로 쓸 수 있습니다.
- 1~18일차는 예문이 3개씩 들어 있고, 19일차부터는 예문을 추가하는 중입니다.
- 예문이 추가된 엑셀을 받으면 **엑셀 불러오기 → 기존 단어에 추가**를 누르세요. 학습 기록은 그대로 유지됩니다.

## 기능
- **오늘의 학습**: 시작 일차~끝 일차를 골라서 문제 풀기, 카드 뒤집기, 복습, 오답노트를 합니다.
- **일차별 학습**: 1~41일차마다 문제, 카드, 복습, 오답노트가 있습니다. 보기 1(격자)과 보기 2(목록)로 볼 수 있습니다.
- **문제**: 4지선다입니다. 답을 고르면 O/X와 효과음이 나오고, 발음을 자동으로 읽어 줍니다.
- **카드**: 탭하면 뒤집히면서 발음이 나옵니다. 중간에 나가도 이어서 볼 수 있습니다.
- **오답노트**: 틀린 단어가 모이고, 2번 연속 맞히면 빠집니다.
- **단어 목록**: 일차별 개수와 4,045개 대비 진행을 확인할 수 있습니다.
- **백업**: 단어 목록 → 백업 파일 저장 / 백업에서 복원

## 알아둘 점
- 홈 화면에서 앱을 삭제하면 학습 기록도 지워집니다. 가끔 백업해 두세요.
- 발음이 안 나오면 아이패드 **설정 → 손쉬운 사용 → 읽기 및 말하기 → 음성 → 일본어**에서 음성을 내려받으세요.
- 앱 파일을 새로 올린 뒤 변경이 바로 안 보이면, 앱을 한 번 완전히 닫았다가 다시 여세요.
